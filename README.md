# БалансПро — сайт бухгалтерской компании

Статический сайт без сборки: бухгалтерский аутсорсинг в Минске, отрасли, услуги, порядок работы, сравнение со штатным бухгалтером и форма заявки. Отдельная страница — «Финансовый директор на аутсорсе».

Откройте `index.html` в браузере или раздайте папку любым статическим сервером, например `python3 -m http.server`.

- `index.html`, `styles.css`, `script.js` — главная страница, общие стили и скрипты (меню, модальное окно, формы, появление блоков)
- `_src/` — контент внутренних страниц: `findir.html` («Финансовый директор на аутсорсе»), `rekvizity.html` (справочник реквизитов), `privacy.html` (политика обработки персональных данных), `404.html`
- `build.py` — собирает из `_src/` и общих частей главной (шапка, подвал, контакты, иконки, `<head>`) страницы `findir/`, `rekvizity/`, `privacy/`, `404.html`, а также `sitemap.xml` и `robots.txt`. После правок главной или `_src/` запустите `python3 build.py`; при деплое он запускается автоматически
- `assets/` — фотографии, иконки сайта (`favicon.svg`, PNG для Apple и браузеров) и картинка-превью для соцсетей и мессенджеров `og-image.jpg`

## Фотографии

`assets/photos/` — фотографии заказчика: бухгалтер на первом экране, отрасли (строительство, розница, кофейня, грузоперевозки) и консультация в блоке «Обсудим вашу задачу?».

## Справочник реквизитов

Страница `/rekvizity/` — реквизиты для уплаты 16 видов платежей (налоги, ФСЗН, Белгосстрах) по инспекциям МНС и отделам ФСЗН Минска и Минской области. Контент страницы — `_src/rekvizity.html`, логика — `assets/rekvizity.js`, данные — `assets/data/rekvizity.json` (взяты с https://ketuta.by/rekvizity-uplaty-nalogov/, дата сверки хранится в поле `checked` и выводится на странице).

Обновление данных: сохраните страницу источника как HTML и выполните
`python3 tools/parse_ketuta.py ketuta.html ketuta.json`, затем `python3 tools/ketuta_to_site.py ketuta.json ГГГГ-ММ-ДД`. Реквизиты бюджета меняются (последний раз — с 10.05.2024), поэтому раз в квартал сверяйте их с nalog.gov.by и minfin.gov.by.

## Актуальные показатели

Страница `/pokazateli/` строится `build.py` из `assets/data/pokazateli.json`. Сайт пересобирается каждый день в 06:17 по Минску; перед сборкой `tools/update_pokazateli.py` берёт свежие значения:

- базовая величина, базовая арендная величина, БПМ — справочные таблицы bii.by;
- ставка рефинансирования — API Национального банка (`api.nbrb.by/refinancingrate`).

Если источник недоступен или значение выглядит подозрительно, остаётся последнее известное, а в журнале сборки появляется предупреждение. МЗП, пособие до 3 лет и ставки налогов меняются вручную в JSON: у каждого есть `review_by`.

Напоминания приходят на почту по понедельникам (задача `notify`): за две недели до `review_by` и если автоматический источник не сработал. Когда всё в порядке, писем нет. Нужны секреты репозитория (Settings → Secrets and variables → Actions):

- `MAIL_USERNAME` — адрес Gmail, с которого и на который приходит письмо;
- `MAIL_PASSWORD` — пароль приложения Gmail (Аккаунт Google → Безопасность → Пароли приложений; нужна двухэтапная аутентификация).

Пробное письмо: Actions → Deploy to GitHub Pages → Run workflow → отметить «Send the indicators e-mail…».

## Заявки в Telegram

Формы на сайте отправляют заявки в Telegram через веб-приложение Google Apps Script — так токен бота не попадает в открытый код сайта. Код посредника — `tools/telegram-form.gs`, инструкция по установке — в его начале. Адрес веб-приложения вставляется в `FORM_ENDPOINT` в начале блока форм в `script.js` (не забудьте поднять `script.js?v=` в `index.html` и пересобрать). Пока адреса нет, форма честно пишет, что не подключена, и предлагает позвонить. Скрытое поле `website` ловит спам-ботов, а посредник принимает не больше 30 заявок в час.

## SEO

- У каждой страницы свои title, description, canonical и Open Graph; у 404 — `noindex`
- Микроразметка schema.org (JSON-LD): компания `AccountingService` со списком услуг на главной, `Service` и хлебные крошки на внутренних страницах
- `sitemap.xml` и `robots.txt` генерируются сборкой; добавьте sitemap в Google Search Console и Яндекс.Вебмастер
- Публикуются только файлы сайта: `_src/`, `build.py` и README в интернет не попадают

Когда появится свой домен: замените `https://jmsbrn.github.io/balans-pro/` на новый адрес в `SITE_URL` в `build.py` и в `<head>` файла `index.html`, затем запустите `python3 build.py`. В микроразметку компании стоит добавить реальные адрес и телефон (`address`, `telephone`), как только они появятся на сайте.

## Публикация

Сайт деплоится на GitHub Pages workflow-ом `.github/workflows/pages.yml` при каждом пуше в `main`: https://jmsbrn.github.io/balans-pro/

## Ветки

- `main` — текущий сайт (дизайн по макету заказчика), публикуется на https://jmsbrn.github.io/balans-pro/
- `start` — прежняя версия сайта, сохранена для истории
- `variant-2` — ветка, в которой разрабатывался текущий дизайн; уже перенесена в `main`

## Перед запуском

Замените заглушки: телефон, e-mail, адрес, ссылки на Telegram/Viber а в `_src/privacy.html` — реквизиты оператора, срок хранения и дату редакции (текст политики стоит согласовать с юристом). Формы пока проверяют поля только в браузере — для отправки заявок нужно подключить обработчик (почта, Telegram-бот или CRM).
