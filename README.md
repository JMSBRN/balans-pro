# БалансПро — сайт бухгалтерской компании

Статический сайт без сборки: бухгалтерский аутсорсинг в Минске, услуги, партнёрство с сетью кофеен VARKA, сравнение со штатным бухгалтером, отзывы и форма заявки. Отдельная страница — «Финансовый директор на аутсорсе».

Откройте `index.html` в браузере или раздайте папку любым статическим сервером, например `python3 -m http.server`.

- `index.html`, `styles.css`, `script.js` — главная страница, общие стили и скрипты (меню, модальное окно, формы, появление блоков)
- `_src/` — контент внутренних страниц: `findir.html` («Финансовый директор на аутсорсе»), `privacy.html` (политика обработки персональных данных), `404.html`
- `build.py` — собирает из `_src/` и общих частей главной (шапка, подвал, контакты, иконки, `<head>`) страницы `findir/`, `privacy/`, `404.html`, а также `sitemap.xml` и `robots.txt`. После правок главной или `_src/` запустите `python3 build.py`; при деплое он запускается автоматически
- `assets/` — логотип партнёра, иконки сайта (`favicon.svg`, PNG для Apple и браузеров) и картинка-превью для соцсетей и мессенджеров `og-image.jpg`

## Фотографии

`assets/photos/` — фотографии из макета заказчика (бухгалтер на первом экране, отрасли, строительство, блок «Обсудим вашу задачу?»). Это фрагменты макетов, поэтому разрешение невысокое: замените их оригиналами в хорошем качестве с теми же именами файлов — вёрстка подхватит их без правок.

## SEO

- У каждой страницы свои title, description, canonical и Open Graph; у 404 — `noindex`
- Микроразметка schema.org (JSON-LD): компания `AccountingService` со списком услуг на главной, `Service` и хлебные крошки на внутренних страницах
- `sitemap.xml` и `robots.txt` генерируются сборкой; добавьте sitemap в Google Search Console и Яндекс.Вебмастер
- Публикуются только файлы сайта: `_src/`, `build.py` и README в интернет не попадают

Когда появится свой домен: замените `https://jmsbrn.github.io/balans-pro/` на новый адрес в `SITE_URL` в `build.py` и в `<head>` файла `index.html`, затем запустите `python3 build.py`. В микроразметку компании стоит добавить реальные адрес и телефон (`address`, `telephone`), как только они появятся на сайте.

## Публикация

Сайт деплоится на GitHub Pages workflow-ом `.github/workflows/pages.yml` при каждом пуше в `main`: https://jmsbrn.github.io/balans-pro/

## Перед запуском

Замените заглушки: телефон, e-mail, адрес, ссылки на Telegram/Viber и примеры отзывов, а в `_src/privacy.html` — реквизиты оператора, срок хранения и дату редакции (текст политики стоит согласовать с юристом). Формы пока проверяют поля только в браузере — для отправки заявок нужно подключить обработчик (почта, Telegram-бот или CRM). Упоминание VARKA и логотип публикуйте с согласия сети.
